# Retrieval Impact Notes

## 3 Examples Where Retrieval Clearly Helped

### Example 1
**Question:** What is the difference between horizontal scaling and vertical scaling in cloud computing?

**Explanation:** Retrieval provided relevant cloud-scaling information, helping the model distinguish adding more machines from increasing the resources of an existing machine.

### Example 2
**Question:** What is a cloud tagging strategy and why is it useful?

**Explanation:** Retrieval supplied the relevant information about tagging resources, allowing the model to give a more grounded explanation of how tags help organize and manage cloud resources.

### Example 3
**Question:** What are the benefits of using infrastructure as code?

**Explanation:** Retrieval provided information about infrastructure-as-code practices, which helped the model answer using the provided knowledge rather than relying only on its general training.

## 3 Examples Where Retrieval Did Not Clearly Help

### Example 4
**Question:** Write a simple bash script that prints "Hello World".

**Explanation:** Retrieval was not necessary because the task is a basic coding operation that does not require information from the retrieved cloud knowledge.

### Example 5
**Question:** What is 2 + 2?

**Explanation:** Retrieval did not provide meaningful additional value because the answer is a simple calculation that does not depend on the retrieved context.

### Example 6
**Question:** Explain what a variable is in programming.

**Explanation:** Retrieval had little impact because the concept is general programming knowledge and does not require the specific cloud information in the knowledge base.
